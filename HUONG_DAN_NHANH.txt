  HƯỚNG DẪN NHANH

MÔ HÌNH
  Server 1 (VMware máy bạn)     : 172.16.228.141  MySQL + LOCK MANAGER
  Server 2 (VMware máy bạn bè)  : 192.168.161.131 MySQL + replica
  Client 1 (máy bạn)            : 172.26.40.121  ROLE=CLIENT1
  Client 2 (máy bạn bè)         : 172.26.82.95   ROLE=CLIENT2

  Mọi thao tác TẠO / XÓA / KHÓA đều đi về Server 1,
  sau đó MySQL đồng bộ hai chiều (GTID) sang Server 2.

----------------------------------------------------------
BƯỚC 1 – CÀI MYSQL
----------------------------------------------------------
  Server 1 (Ubuntu):
     sudo bash scripts/setup_mysql_ubuntu.sh 1

  Server 2 (Windows, PowerShell Administrator):
     Set-ExecutionPolicy -Scope Process Bypass -Force
     .\scripts\setup_mysql_windows.ps1 -ServerId 2 -RootPass "mat_khau_root"

  (Nếu Server 2 chạy Ubuntu: sudo bash scripts/setup_mysql_ubuntu.sh 2)

  Script tự: bật GTID + binlog + log_replica_updates, bind 0.0.0.0,
  tạo DB shared_records + bảng + user, mở firewall 3306.

----------------------------------------------------------
BƯỚC 2 – BẬT ĐỒNG BỘ HAI CHIỀU
----------------------------------------------------------
  Trên Server 1: sudo bash scripts/setup_replication.sh <IP_SERVER_2>
  Trên Server 2: .\scripts\setup_replication_windows.ps1 -PeerHost <IP_SERVER_1>

  Kiểm tra:  SHOW REPLICA STATUS\G
  → Replica_IO_Running: Yes
    Replica_SQL_Running: Yes

----------------------------------------------------------
BƯỚC 3 – CHỌN CẤU HÌNH THEO MÁY
----------------------------------------------------------
  Linux  : cp configs/client1.properties config.properties
  Windows: run.bat client2        (tự copy configs\client2.properties)

  Vai trò có sẵn trong configs/:
     client1 | client2 | server1 | server2
     desktop_server1_client1 | vm_server2 | vm_client2

  Quy tắc: lockManager.host = IP SERVER 1 (giống nhau trên mọi máy)

----------------------------------------------------------
BƯỚC 4 – CHẠY APP
----------------------------------------------------------
  Linux  : ./run.sh                (JDK 17+: sudo apt install default-jdk)
  Windows: run.bat client2         (JDK 17/21: https://adoptium.net)
           hoặc nhấp đúp chay_client2.bat

  App cũng chạy được trên server: run.bat server2 / ./run.sh server1

----------------------------------------------------------
DEMO 6 BƯỚC
----------------------------------------------------------
  1. Client 1 tạo SV010          → Client 2 tải lại thấy SV010   (đồng bộ)
  2. Client 2 tạo lại SV010      → "Mã đã tồn tại"               (chống trùng)
  3. Client 1 khóa SV010         → nhận LOCK_TOKEN
  4. Client 2 khóa SV010         → "đang được sử dụng"
  5. Client 1 giải phóng         → Client 2 khóa lại được        (đúng token)
  6. Client 1 xóa SV010          → Client 2 tải lại không còn    (xóa + đồng bộ)

LƯU Ý QUAN TRỌNG
----------------------------------------------------------
  IP 172.16.x.x và 192.168.x.x của VMware là mạng NAT nội bộ,
  KHÔNG ping chéo giữa 2 máy. Phải chuyển VM sang BRIDGED
  hoặc dùng NAT port forwarding 3307. Xem:
     docs/05_HUONG_DAN_WINDOWS.md  (mục 1)
